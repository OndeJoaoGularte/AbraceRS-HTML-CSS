Protótipo da landing page do **Instituto AbraceRS**, desenvolvido com HTML, CSS e JavaScript puros, sem frameworks de estilo ou bibliotecas externas de UI. O objetivo foi estruturar a identidade visual e as seções principais do site institucional.

> **Contexto:** site provisório publicado enquanto a versão definitiva (Angular + Supabase) estava em desenvolvimento.

---

## 🎯 Objetivo do Projeto

Criar a primeira versão web do instituto com linguagem web nativa, focando em estrutura semântica, layout responsivo e interações simples no front-end, como base para evoluções futuras do projeto.

---

## 🚀 Funcionalidades

1. **Carrossel de imagens:** Exibição automática das fotos das ações do instituto, com navegação manual por indicadores.
2. **Seção de doação:** Dados bancários, chave Pix e QR Code para facilitar contribuições.
3. **Modal de doação rápida:** Botão flutuante que abre o QR Code em sobreposição.
4. **Quem Somos:** Apresentação do instituto e da diretoria.
5. **Como Atuamos:** Descrição da atuação humanitária e campanhas em destaque.
6. **Menu sticky:** Navegação que se fixa no topo ao rolar a página.
7. **Rodapé com contatos:** Telefone, e-mail, endereço e redes sociais.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica da página e dos conteúdos.
* **CSS3:** Estilização com variáveis CSS, Flexbox e media queries para responsividade.
* **JavaScript (Vanilla):** Carrossel automático, modal de doação e comportamento do menu fixo.

---

## 🧠 Conceitos Aplicados

* **HTML semântico:** Organização da página em `header`, `nav`, `main`, `section` e `footer`.
* **CSS custom properties:** Uso de variáveis para cores e tipografia, facilitando a manutenção do visual.
* **Layout com Flexbox:** Alinhamento e distribuição dos elementos nas seções.
* **Responsividade:** Ajustes de layout para diferentes tamanhos de tela.
* **DOM e eventos:** Manipulação de elementos e escuta de scroll/clique para o menu sticky e o modal.
* **Interação visual:** Carrossel com `setInterval` e troca automática de slides.
